# HUMAN.EXE — The Future Was Never Written

> **The future was never written. It was shaped by the choices we made.**

HUMAN.EXE is an interactive digital archaeology experience set in the year 2075. Explore five eras of human technological evolution, discover historical artifacts, make decisions that shape possible futures, and uncover what humanity chose to preserve — or forget.

## Project Overview

Imagine entering a digital archive in 2075, where the history of humanity has become something to investigate.

HUMAN.EXE takes users through five chapters of technological evolution, from the discovery of fire to the age of intelligent machines. Each chapter combines immersive 3D environments, historical information, interactive artifacts and meaningful choices.

Your decisions influence the direction of the archive and lead to different possible outcomes for humanity.

## Key Features

### 1. Cinematic Opening Experience
- Scroll-driven introductory sequence.
- Animated transitions and immersive visual storytelling.
- A journey into the digital archive of 2075.

### 2. Five Interactive Historical Chapters

- **Chapter 01 — The First Spark:** Discover early human innovation, fire, tools and communication.
- **Chapter 02 — Engines of Change:** Explore the Industrial Revolution, steam engines and mechanisation.
- **Chapter 03 — The Silent Code:** Discover the evolution of computing, programming and information.
- **Chapter 04 — The Connected World:** Explore the internet, global connectivity and digital identity.
- **Chapter 05 — The Age of Machines:** Enter a speculative 2075 and explore artificial intelligence and human agency.

### 3. Branching Decisions & Multiple Endings
- Make decisions throughout the five chapters.
- Explore 48 possible decision paths.
- Discover five possible 2075 endings.
- Track your Humanity Index through Innovation, Connection and Human Agency.

### 4. The 2075 Archivist
An offline, rule-based knowledge assistant that helps users explore the archive.

- Ask questions about historical events, people and technologies.
- Explore the connection between your decisions and the archive.
- Understand your Humanity Index and ending.
- Distinguish documented historical information from fictional 2075 scenarios.
- Uses a local knowledge base and does not require an API key or external AI service.

### 5. Hidden Discoveries & Archive Exploration
- Discover hidden artifacts and lost memories.
- Explore corrupted files and reconstruct archive fragments.
- Uncover clues through the Archivist's Journal.
- Track discoveries and progress throughout the experience.

### 6. Personal Archive Report
- Generate an archive dossier based on your journey.
- Review your decisions and ending.
- Print or save the report as HTML/PDF through the browser.
- Export your archive report as a TXT file.

### 7. Immersive Audio & Accessibility
- Procedurally generated ambient audio and sound effects.
- Optional narration.
- Adjustable sound controls.
- Keyboard-friendly dialogs and reduced-motion support.

## Getting Started

### Prerequisites
- Node.js
- npm

### 1. Clone the Repository

```bash
git clone https://github.com/veryVanshika801/HUMAN.EXE-The-Future-Was-Never-Written.git
```

### 2. Navigate to the Project

```bash
cd HUMAN.EXE-The-Future-Was-Never-Written
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

**No API key or external AI configuration is required.**

## Deployment

HUMAN.EXE can be deployed using **Vercel**.

1. Import this GitHub repository into Vercel.
2. Select Vite as the framework preset.
3. Set the build command to `npm run build`.
4. Set the output directory to `dist`.
5. Deploy the project.

No Gemini API key or environment variable is required for the offline Archivist.
